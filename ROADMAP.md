# Roadmap

## 🎯 Vision

Make pi-saia-plugin the most robust, feature-rich, and user-friendly way to use SAIA models with the pi coding agent.

## ✅ Completed (v0.1.0)

- [x] TypeScript plugin for pi
- [x] Model list fetching from SAIA API
- [x] Profile-based model selection
- [x] Rich model metadata
- [x] Shell scripts for manual generation
- [x] Memory layer (caching, metrics, usage tracking)
- [x] 5 management skills
- [x] JSON schema validation
- [x] Interactive setup wizard
- [x] Installation scripts (Linux, macOS, Windows)
- [x] Documentation (README, FAQ, ARCHITECTURE)

## 🚀 Upcoming (v0.2.0)

### High Priority
- [ ] **Auto-refresh** - Background model list updates without restart
- [ ] **Custom profiles** - User-defined model sets via config files
- [ ] **Model health checks** - Automatic testing of model capabilities
- [ ] **Quota monitoring** - Track SAIA API usage and limits

### Medium Priority
- [ ] **Fallback models** - Automatic switch to similar models on failure
- [ ] **Model benchmarking** - Performance comparison across models
- [ ] **Context-aware recommendations** - AI-driven model suggestions
- [ ] **Multi-provider support** - Use SAIA + other providers simultaneously

### Low Priority
- [ ] **GUI setup** - Web-based configuration interface
- [ ] **Plugin marketplace** - Package for pi plugin registry
- [ ] **Docker image** - Pre-configured container with pi + SAIA
- [ ] **CI/CD pipeline** - Automated testing and releases
